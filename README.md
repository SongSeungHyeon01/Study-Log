# Study-Log

논문이나 기술 글을 읽고 정리하는 곳입니다.

## 공부하는 것

- AI 에이전트 - 하네스, 스킬, 에이전트 평가
- LLM - 학습 방법, test-time scaling, 모델이 쓰는 글의 특징
- 소프트웨어 개발 - 아키텍처, 코드 품질, AI랑 같이 개발하는 법
- 개발자 커리어 - AI 시대에 개발자가 하는 일, 필요한 역량

## 읽는 자료

- arXiv, OpenReview 논문
- NAVER D2 같은 기술 블로그
- 개발 관련 아티클

## 정리 방식

자료 하나당 파일 하나, 이름은 `devlog/읽은날짜-주제.md`로 합니다.

보통 이런 순서로 씁니다.

1. 제목, 저자, 출처, 공개일, 읽은 날
2. 한 줄 요약
3. 핵심 내용
4. 읽다가 궁금했던 것
5. 생각해 볼 점

# 📚 Study-Log

> 논문, 기술 블로그, 아티클을 읽고 내 말로 다시 풀어 쓰는 공부 노트

읽고 끝내지 않고, 이해한 만큼 정리하고, 질문을 던지고, 다른 자료와 연결해 둡니다.

## 🔍 공부하는 것

- **AI 에이전트:** 하네스, 스킬, 도구 사용, 에이전트 평가 방법
- **LLM:** 학습 방식(RLHF, RLVR), 추론 성능 높이기(test-time scaling), 모델이 만들어 내는 언어의 특성
- **소프트웨어 개발:** 아키텍처, 코드 품질, AI와 함께 개발하는 방식
- **개발자의 성장:** AI 시대에 개발자의 역할, 필요한 역량, 커리어

## 📖 주로 읽는 자료

- **논문:** arXiv, OpenReview, 학회·워크숍 발표 논문
- **기술 블로그:** NAVER D2 등 현업 개발 조직의 기술 블로그
- **아티클:** 업계 동향과 개발 문화를 다룬 글

## ✍️ 정리 방식

자료 하나를 파일 하나에 담고, 파일 이름은 `devlog/읽은날짜-주제.md`로 짓습니다.

1. **자료 정보:** 제목, 저자, 출처, 공개일, 읽은 날
2. **한 줄 요약**
3. **핵심 내용:** 문제 제기, 접근 방법, 결과, 저자의 주장
4. **Q&A:** 읽다가 생긴 질문과 답
5. **생각해 볼 점:** 한계, 다른 자료와 이어지는 지점
